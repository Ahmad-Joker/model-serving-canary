# Master prompt — Model Serving Canary
Build a fully local, reproducible model rollout gate for teams that need to compare baseline and candidate model predictions on the same labeled cases before promoting a model. Target users: junior ML engineers and MLOps engineers. Evidence: Moonpig data scientist role (Python/SQL, reproducibility, monitoring), Circadia MLOps role (canary rollout, model monitoring), Loft Orbital AI/ML intern (accuracy/latency benchmarking), ANYbotics AI Platform intern (testable Python model inference). Official URLs in docs/research.md. Competing tools: MLflow model registry and Evidently monitoring; this is a small standalone offline evaluator, not a replacement.

MVP: CSV rows case_id,label,baseline_prediction,candidate_prediction,baseline_latency_ms,candidate_latency_ms. Validate unique IDs, binary labels/predictions, finite nonnegative latency, no missing values. Compute accuracy, precision, recall, F1, latency mean and p95 for each. Configurable gates: maximum accuracy drop, minimum candidate F1, maximum p95 latency ratio. Output JSON with PASS/FAIL, per-gate findings and metrics; exit 0 PASS, 1 FAIL, 2 invalid input. Never call a remote service or deploy. Input data synthetic only.
